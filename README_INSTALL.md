# INKA One-Click Installer

## Требования
- Аккаунт Google Cloud, включён биллинг, создан проект.
- Установлены gcloud, docker, Python >= 3.10.
- Создан Telegram-бот через BotFather.

## Установка
1. Клонируйте репозиторий, перейдите в папку.
2. Запустите:
   ```
   python3 tools/install_and_deploy.py
   ```
3. После деплоя откройте ссылку вида https://...run.app/setup и следуйте мастеру настройки.

## Проверка
- После настройки бот должен отвечать в Telegram.
- Админ-панель доступна по /admin.
