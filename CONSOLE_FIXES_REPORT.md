#### 1. **JavaScript синтаксис ошибки в template literal**
**Строка**: `src/web/pages.py` - функция `loadMasters()`
**Проблема**: 
```javascript
// ❌ НЕПРАВИЛЬНО - onclick внутри template literal с ${} переменной
onclick="editMaster(${m.id})"
```
**Почему ошибка**: Когда вы используете backtick (`) для template literal, `${...}` это JavaScript переменная. Но она находится внутри строкового атрибута `onclick=""`, вызывая синтаксическую ошибку.

**Решение**: 
```javascript
// ✅ ПРАВИЛЬНО - использование data-* атрибутов + event listener
<button class="btn-edit" data-id="${m.id}">✏️</button>

// JS код:
document.querySelectorAll('.btn-edit').forEach(btn => {
    btn.addEventListener('click', () => editMaster(btn.dataset.id));
});
```
