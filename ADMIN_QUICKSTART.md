# 🎯 Быстрый старт: Админ-функции INKA

## Что произошло?

✅ INKA теперь имеет **6 новых инструментов управления**, доступных **ТОЛЬКО администраторам**!

## 👑 Кто может использовать эти функции?

Только администраторы - те, чьи ID указаны в `ADMIN_IDS`:

```bash
# .env или переменные окружения
ADMIN_IDS=438407739,457343487
```

## 🚀 Как использовать?

Просто напишите INKA в Telegram, что вы хотите сделать:

### 1. **Редактировать мастера**
```
"Обнови данные мастера 1: имя Анна, ставка 5000"
```

### 2. **Редактировать услугу**
```
"Измени цену на услугу 'Тату маленькая' на 3000 рублей"
```

### 3. **Добавить выходной день**
```
"Добавь выходной для мастера 1 на 25 декабря с 10:00 до 18:00"
```

### 4. **Отменить запись**
```
"Отмени запись номер 42 - клиент отменил"
```

### 5. **Получить статистику**
```
"Сколько дохода было в декабре?"
"Дай статистику по записям за месяц"
```

### 6. **Отправить рассылку**
```
"Отправь всем клиентам: новое предложение скидка 20%!"
```

## 🔐 Что происходит если я НЕ администратор?

❌ INKA откажет в доступе:
```
"❌ ДОСТУП ЗАПРЕЩЁН! Функция 'edit_master' доступна ТОЛЬКО администраторам."
```

## 📋 Список админ-функций

| Функция | Описание | Пример |
|---------|---------|--------|
| **edit_master** | Редактировать мастера | "Обнови имя мастера 1 на Анна" |
| **edit_service** | Редактировать услугу | "Измени цену услуги на 3000" |
| **add_schedule_slot** | Добавить временной слот | "Добавь выходной на 25 декабря" |
| **cancel_booking** | Отменить запись | "Отмени запись 42" |
| **export_statistics** | Получить статистику | "Дай статистику по доходам" |
| **send_broadcast_message** | Отправить рассылку | "Отправь всем сообщение..." |

## ✅ Все системы готовы!

Просто напишите админ команду INKA и она её выполнит! 🚀
