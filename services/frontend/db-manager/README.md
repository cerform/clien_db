# DB Manager Frontend (PoC)

This is a minimal React + Vite proof-of-concept for the DB Manager UI.

Quick start:

```
cd services/frontend/db-manager
npm install
npm run dev
```

It expects the backend to be available at `/api/*` (same host). This PoC intentionally uses a test admin token `admin_token_1` for convenience; replace with a secure auth mechanism for production.
