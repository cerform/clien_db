# 🛠️ Scripts - Утилиты управления БД

Вспомогательные скрипты для управления данными.

## 📋 Скрипты

### `add_data.py`
**Цель**: Добавить новые мастера или услуги

**Использование**:
```bash
# Интерактивное добавление
python scripts/add_data.py
```

**Примеры**:
```bash
# Добавить нового мастера
# Введите: мастер → укажите данные → добавляется в таблицу

# Добавить новую услугу
# Введите: услуга → укажите данные → добавляется в таблицу
```

---

### `add_schedule.py`
**Цель**: Добавить расписание для мастера

**Использование**:
```bash
# Добавить расписание
python scripts/add_schedule.py

# Введите:
# - Master ID (например, m_anna_levi)
# - День недели (Monday, Tuesday, ... Sunday)
# - Время начала (10:00)
# - Время окончания (18:00)
```

**Результат**: 7 новых расписаний (по одному для каждого дня недели)

**Пример**:
```
Master ID: m_anna_levi
Days: Monday-Sunday
Time: 10:00-18:00
→ Создано 7 записей расписания
```

---

### `fix_schedule.py`
**Цель**: Исправить некорректное расписание

**Использование**:
```bash
# Удалить некорректные записи
python scripts/fix_schedule.py
```

**Что делает**:
1. Находит записи расписания с несуществующими master_id
2. Удаляет их (их нельзя использовать)
3. Выводит отчет об удаленном

**Пример**:
```
Найдены некорректные записи:
- sch_omer_001 (master m_omer - не существует)
- sch_sarah_002 (master m_sarah - не существует)

Удалить? (y/n): y
✅ 14 некорректных записей удалено
```

---

### `sync_database.py`
**Цель**: Синхронизировать данные между Sheets и Calendar

**Использование**:
```bash
# Полная синхронизация
python scripts/sync_database.py
```

**Что делает**:
1. Загружает расписание из Sheets
2. Синхронизирует с Google Calendar
3. Проверяет целостность данных
4. Выводит отчет

**Результат**:
```
Загружено мастеров: 3
Загружено услуг: 8
Синхронизировано расписаний: 21
Синхронизировано календарей: 1
✅ Синхронизация завершена успешно
```

---

### `get_calendar_id.py`
**Цель**: Получить ID Google Calendar

**Использование**:
```bash
# Получить календарь ID
python scripts/get_calendar_id.py
```

**Результат**:
```
Доступные календари:
1. Primary Calendar
   ID: calendar_id@group.calendar.google.com
   ← Это нужно скопировать в GOOGLE_CALENDAR_ID

Скопируйте ID в .env:
GOOGLE_CALENDAR_ID=calendar_id@group.calendar.google.com
```

**Когда использовать**: При первой настройке календаря

## 🚀 Типичные задачи

### Добавить нового мастера
```bash
python scripts/add_data.py
# Выбрать: мастер
# Заполнить данные
# Автоматически добавляется в таблицу
```

### Добавить расписание для мастера
```bash
python scripts/add_schedule.py

# Выбрать время (по умолчанию 10:00-18:00)

```

### Проверить целостность данных
```bash
python scripts/sync_database.py
# Проверяет что все master_id существуют
# Проверяет что все service_id существуют
# Синхронизирует с Calendar
```

### Получить Calendar ID
```bash
python scripts/get_calendar_id.py
# Выводит доступные календари и их ID
# Скопировать ID в .env
```

### Исправить ошибки расписания
```bash
python scripts/fix_schedule.py
# Находит и удаляет некорректные записи
# Выводит отчет об изменениях
```

## 🔄 Автоматизация

Можно использовать в cron для регулярной синхронизации:

```bash
# Синхронизировать каждый час
0 * * * * /usr/bin/python3 /path/to/scripts/sync_database.py

# Проверить целостность каждый день в 00:00
0 0 * * * /usr/bin/python3 /path/to/scripts/fix_schedule.py
```

## 🐛 Решение проблем

**Проблема**: "Master not found"
**Решение**: Проверить что master_id существует в таблице masters

**Проблема**: "Duplicate entry"
**Решение**: Скрипт добавляет с уникальным ID автоматически

**Проблема**: "Calendar sync failed"
**Решение**: Проверить:
1. Google Calendar API включена
2. GOOGLE_CALENDAR_ID установлен
3. Service Account имеет доступ
