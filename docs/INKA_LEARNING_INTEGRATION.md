# 🧠 Интеграция INKA с системой обучения через Telegram

Как ИНКА улучшается на основе примеров и исправлений через админ-панель Telegram.

## 📊 Архитектура обучения

```
Admin (Telegram)
      ↓
 Добавляет пример обучения
      ↓
 INKA_Training sheet
      ↓
 InkaLearningSystem
      ↓
 Может быть использовано:
  • В few-shot prompting
  • Для контекстуализации
  • Для улучшения ответов
```

## 🎯 Как это работает

### 1️⃣ Админ добавляет пример

```python
# Через UI админ-панели
/admin → 🧠 Обучить ИНКУ → ➕ Добавить пример

# Данные:
category = "booking"
user_input = "Хочу татушку на руку"
inka_response = "Конечно! Какой размер вас интересует?"
tags = "tattoo,arm,booking"
```

### 2️⃣ Пример сохраняется в БД

```python
# src/services/admin_db_manager.py
learning_system.add_training_example(
    category="booking",
    user_input="Хочу татушку на руку",
    inka_response="Конечно! Какой размер вас интересует?",
    correction="",  # Если админ не исправляет - пусто
    tags="tattoo,arm,booking"
)

# Сохраняется в Google Sheets (лист "INKA_Training"):
# | Timestamp | Category | User Input | INKA Response | Tags |
# |-----------|----------|------------|---------------|------|
# | 2024-01-15 | booking | Хочу татушку на руку | ... | tattoo,arm,booking |
```

### 3️⃣ ИНКА может использовать эти примеры

```python
# src/ai/advanced_inka.py

    """
    Улучшенная обработка с примерами обучения
    """

    # Создать few-shot prompt
    system_prompt = self.create_system_prompt_with_examples(

    # Отправить запрос в OpenAI с примерами
    response = await openai_client.chat.completions.create(
        model="gpt-4",
        system=system_prompt,  # <- содержит примеры!
        messages=[...]
    )
    
    return response
```

## 📋 Структура INKA_Training листа

Автоматически создается при первом добавлении примера:

```
┌─────────────┬──────────────┬─────────────────────┬──────────────────────┬────────────┬────────────┐
│ Timestamp   │ User ID      │ Category            │ User Input           │ INKA Resp  │ Tags       │
├─────────────┼──────────────┼─────────────────────┼──────────────────────┼────────────┼────────────┤
│ 2024-01-15  │ admin_123    │ greeting            │ Привет!              │ Привет!... │ greeting   │
│ 2024-01-15  │ admin_123    │ booking             │ Хочу запись          │ Конечно!.. │ booking    │
│ 2024-01-15  │ admin_456    │ question            │ Какова цена?         │ Цена...    │ pricing    │
│ 2024-01-16  │ admin_123    │ booking             │ На завтра?           │ Смотрим... │ booking    │
└─────────────┴──────────────┴─────────────────────┴──────────────────────┴────────────┴────────────┘

Полные поля:
- Timestamp: Когда добавлен пример
- User ID: Кто добавил
- Category: Категория (greeting, booking, question, help, other)
- User Input: Что написал клиент
- INKA Response: Правильный ответ ИНКИ
- Correction: Если админ исправляет неправильный ответ ИНКИ
- Tags: Теги для фильтрации (#booking, #tattoo, #question, etc)
- Rating: Оценка качества ответа (1-5 звезд)
```

## 🔄 Жизненный цикл примера

### Сценарий 1: Добавление нового примера

```
1. Админ в Telegram:
   /admin → 🧠 Обучить ИНКУ → ➕ Добавить пример
   
   Выбирает категорию: "booking"
   Пишет: "Запиши меня на завтра"
   ИНКА должна сказать: "Конечно! Какой час вас устраивает?"

2. Пример сохраняется:
   add_training_example(
       category="booking",
       user_input="Запиши меня на завтра",
       inka_response="Конечно! Какой час вас устраивает?",
       tags="booking,tomorrow"
   )

3. Записывается в INKA_Training лист

4. Следующий раз когда пользователь пишет что-то похожее:
   ИНКА получает этот пример в few-shot prompt
   и дает более точный ответ
```

### Сценарий 2: Исправление неправильного ответа ИНКИ

```
1. Админ видит в логах неправильный ответ ИНКИ:
   Клиент: "Сколько стоит татуировка?"
   ИНКА: "Я не знаю"  ❌

2. Админ добавляет исправление:
   /admin → 🧠 Обучить ИНКУ → ➕ Добавить пример
   
   category="question"
   user_input="Сколько стоит татуировка?"
   inka_response="Цена зависит от размера и сложности. Обычно от 3000 до 50000 руб"
   correction="Я не знаю"  # Неправильный ответ

3. Записывается и помечается как "улучшение":
   (лист INKA_Improvements)

4. ИНКА анализирует улучшения и учится не давать этот ответ
```

### Сценарий 3: Категоризация примеров

```
Система автоматически группирует примеры:

📚 Примеры обучения (12 всего):
  • Приветствие: 3
  • Запись: 5
  • Вопрос: 2
  • Помощь: 2

Когда клиент пишет новое сообщение:
ИНКА определяет категорию
→ Берет примеры из этой категории
```

## 🧩 Интеграция с Advanced INKA

### Файл: src/ai/advanced_inka.py

```python
class AdvancedINKA:
    """ИНКА с поддержкой обучения через примеры"""
    
    def __init__(self, learning_system: InkaLearningSystem):
        self.learning_system = learning_system
    
    async def process_message(self, message: str, user_id: int = None):
        """
        Обработать сообщение с использованием примеров обучения
        """
        # 1. Определить категорию сообщения
        category = await self.classify_message(message)
        
        # 2. Получить примеры из этой категории
        examples = self.learning_system.get_training_examples(
            category=category,
            limit=5
        )
        
        # 3. Создать few-shot prompt
        system_prompt = self._create_prompt_with_examples(
            examples=examples,
            category=category
        )
        
        # 4. Отправить в GPT-4
        response = await self.gpt_client.create(
            system_prompt=system_prompt,
            user_message=message,
            temperature=0.7
        )
        
        # 5. Логировать для анализа
        self.learning_system.log_interaction(
            user_input=message,
            inka_response=response,
            category=category
        )
        
        return response
    
    def _create_prompt_with_examples(self, examples, category):
        """Создать prompt с примерами"""
        prompt = f"Ты ИНКА - помощник тату-салона. Категория: {category}\n\n"
        prompt += "Примеры правильных ответов:\n"
        
        for ex in examples:
            prompt += f"\nКлиент: {ex['user_input']}\n"
            prompt += f"ИНКА: {ex['inka_response']}\n"
        
        prompt += "\nОтвечай естественно, не копируя примеры дословно."
        return prompt
```

## 🔍 Поиск релевантных примеров

Когда ИНКА обрабатывает новое сообщение, система ищет похожие примеры:

```python
# Методы поиска примеров

1. По категории (основной):
   examples = learning_system.get_training_examples(category="booking")
   # Возвращает примеры категории "booking"

2. По тегам:
   examples = learning_system.get_training_examples(tags="tattoo,arm")
   # Возвращает примеры с тегами tattoo И arm

3. По ключевым словам (семантический поиск):
   examples = learning_system.search_examples(
       query="цена татуировки",
       limit=5
   )
   # Использует embeddings для поиска похожих примеров

4. По рейтингу качества:
   examples = learning_system.get_training_examples(
       category="booking",
       min_rating=4.0
   )
   # Только хорошие примеры с рейтингом >= 4.0
```

## 🚀 Продвинутые техники обучения

### 1. Few-shot Learning

ИНКА учится на основе примеров:

```
Примеры:
Клиент: "Запиши меня"
ИНКА: "Конечно! На какой день?"

Клиент: "Какова цена?"
ИНКА: "Цена зависит от размера"

Новое сообщение:
Клиент: "Я хочу татушку"
ИНКА: (использует примеры выше)
→ Дает релевантный ответ
```

### 2. Chain-of-Thought Learning

Пример с объяснением:

```
Клиент: "Сколько это займет времени?"
Правильный процесс:
1. Определить, о чем спрашивает (время для татуировки)
2. Ответить время на основе размера/сложности
3. Предложить консультацию

ИНКА: "Маленькая татуировка ~1 час, большая ~3-4 часа"
```

### 3. Контекстуальное обучение

Примеры с контекстом:

```
Контекст: Клиент уже записан на 15:00
Новый вопрос: "А я смогу прийти на час раньше?"

ИНКА использует пример:
"Смотрим расписание мастера...
Вижу, что мастер занят с 13:00 до 14:30
К сожалению, час раньше не получится"
```
