# 👑 INKA Admin Functions - Инструменты управления для администраторов

## 📋 Описание

INKA теперь имеет полный набор инструментов управления, доступных **ТОЛЬКО администраторам**!

Администраторы (их ID указаны в переменной окружения `ADMIN_IDS`) могут использовать следующие функции в диалоге с INKA:

## 🔐 Система доступа

### Проверка прав
- Функции управления проверяют, является ли `user_id` администратором
- Если пользователь НЕ админ → ❌ **ДОСТУП ЗАПРЕЩЁН**
- Все попытки логируются для безопасности

### Конфигурация администраторов

**Переменная окружения:**
```bash
ADMIN_IDS=438407739,457343487
```

**В коде:**
```python
# src/config/config.py
admin_ids: List[int] = [438407739, 457343487]
```

## 👑 Доступные функции управления

### 1️⃣ **edit_master** - Редактирование мастера

Изменяет информацию о мастере (имя, телефон, специализацию, ставку).

**Пример использования:**
```
Инка, обнови данные мастера 1: 
- Имя: Анна
- Ставка в час: 5000
- Специализация: Реалистичные портреты
```

**Параметры:**
- `master_id` (обязательно) - ID мастера
- `name` - Новое имя мастера
- `phone` - Телефон
- `specialty` - Специализация (например: "Реалистичные портреты", "Минимализм")
- `rate_per_hour` - Ставка в час (в рублях)

**Ответ:**
```json
{
  "success": true,
  "message": "Мастер Анна успешно обновлен",
  "updated_fields": {
    "Имя": "Анна",
    "Ставка в час": 5000
  }
}
```

---

### 2️⃣ **edit_service** - Редактирование услуги

Изменяет информацию об услуге (название, описание, цену, длительность).

**Пример использования:**
```
Инка, обновите услугу "Тату маленькая":
- Новая цена: 3000
- Длительность: 60 минут
```

**Параметры:**
- `service_id` (обязательно) - ID услуги
- `name` - Новое название
- `description` - Описание
- `price` - Цена услуги (в рублях)
- `duration_minutes` - Продолжительность (в минутах)

**Ответ:**
```json
{
  "success": true,
  "message": "Услуга Тату маленькая успешно обновлена",
  "updated_fields": {
    "Цена": 3000,
    "Длительность (мин)": 60
  }
}
```

---

### 3️⃣ **add_schedule_slot** - Добавление временного слота

Добавляет новый временной слот в расписание мастера.

**Пример использования:**
```
Инка, добавьте выходной день мастеру 1:
- Дата: 2025-12-25
- Время: 10:00 - 18:00
- Примечание: Отпуск
```

**Параметры:**
- `master_id` (обязательно) - ID мастера
- `date` (обязательно) - Дата (YYYY-MM-DD)
- `start_time` (обязательно) - Время начала (HH:MM)
- `end_time` (обязательно) - Время окончания (HH:MM)
- `notes` - Примечания (выходной, отпуск, техническое обслуживание)

**Ответ:**
```json
{
  "success": true,
  "message": "Слот добавлен: 2025-12-25 10:00-18:00",
  "slot": {
    "Мастер ID": "1",
    "Дата": "2025-12-25",
    "Время начала": "10:00",
    "Время окончания": "18:00",
    "Примечание": "Отпуск",
    "Статус": "Доступно"
  }
}
```

---

### 4️⃣ **cancel_booking** - Отмена записи

Отменяет запись клиента с возможностью отправки уведомления.

**Пример использования:**
```
Инка, отмени запись номер 42:
- Причина: Клиент отменил
- Уведомить клиента: да
```

**Параметры:**
- `booking_id` (обязательно) - ID записи
- `reason` - Причина отмены
- `notify_client` - Отправить ли уведомление клиенту (true/false)

**Ответ:**
```json
{
  "success": true,
  "message": "Запись 42 отменена",
  "reason": "Клиент отменил",
  "client_notified": true
}
```

---

### 5️⃣ **export_statistics** - Экспорт статистики

Выгружает статистику по типам (доход, записи, мастера, услуги).

**Пример использования:**
```
Инка, дай статистику по доходам за декабрь:
- Дата начала: 2025-12-01
- Дата конца: 2025-12-31
- Тип: revenue
```

**Параметры:**
- `date_from` - Дата начала (YYYY-MM-DD)
- `date_to` - Дата конца (YYYY-MM-DD)
- `stat_type` - Тип статистики:
  - `revenue` - Доход
  - `bookings` - Записи
  - `masters` - Мастера
  - `services` - Услуги
  - `clients` - Клиенты

**Примеры ответов:**

**Revenue:**
```json
{
  "success": true,
  "stat_type": "revenue",
  "data": {
    "total_revenue": 125000,
    "bookings_count": 25,
    "period": "2025-12-01 to 2025-12-31"
  }
}
```

**Bookings:**
```json
{
  "success": true,
  "stat_type": "bookings",
  "data": {
    "total_bookings": 30,
    "completed": 25,
    "cancelled": 3,
    "scheduled": 2
  }
}
```

---

### 6️⃣ **send_broadcast_message** - Рассылка сообщения

Отправляет сообщение определённой группе клиентов.

**Пример использования:**
```
Инка, отправь всем клиентам сообщение:
"Новое предложение! Скидка 20% на все услуги до конца месяца!"
- Группа: all_clients
```

**Параметры:**
- `message` (обязательно) - Текст сообщения
- `target_group` - Целевая группа:
  - `all_clients` - Все клиенты
  - `recent_clients` - Последние 10 клиентов
  - `vip_clients` - VIP клиенты (с 5+ бронированиями)

**Ответ:**
```json
{
  "success": true,
  "message": "Рассылка подготовлена для 50 клиентов",
  "target_group": "all_clients",
  "recipients_count": 50
}
```

## 🔒 Безопасность

### Что происходит если НЕ-администратор пытается использовать админ-функцию?

```
❌ ДОСТУП ЗАПРЕЩЁН! Функция 'edit_master' доступна ТОЛЬКО администраторам. 
Ваш ID: 123456789, Админы: [438407739, 457343487]
```

### Логирование

Все попытки использования админ-функций логируются:

```
👑 Admin 438407739 has access to edit_master
👑 Admin 438407739 editing master 1: {'name': 'Анна', 'rate_per_hour': 5000}
✅ Master 1 updated: {'Имя': 'Анна', 'Ставка в час': 5000}
```

## 🚀 Интеграция в код

### 1. Инициализация INKA с админ-правами

```python
from src.ai.advanced_inka import get_advanced_inka
from src.config import get_config

config = get_config()

inka = get_advanced_inka(
    api_key=config.openai_api_key,
    assistant_id=config.openai_assistant_id,
    sheets_client=sheets_client,
    calendar_service=calendar_service,
    admin_ids=config.admin_ids  # Передаём админ IDs!
)
```

### 2. В боте (client_handler.py)

```python
# Фреймворк автоматически:
# 1. Получает admin_ids из конфига
# 2. Передаёт их при инициализации INKA
# 3. Проверяет права при вызове функции
# 4. Логирует все попытки доступа
```

### 3. Проверка прав в handle_function_call()

```python
def handle_function_call(self, function_name: str, arguments: Dict) -> str:
    admin_functions = [
        "edit_master", "edit_service", "add_schedule_slot", 
        "cancel_booking", "export_statistics", "send_broadcast_message"
    ]
    
    if function_name in admin_functions:
        current_user = int(self._current_user_id)
        if current_user not in self.admin_ids:
            return {"error": "❌ ДОСТУП ЗАПРЕЩЁН! Функция доступна ТОЛЬКО администраторам"}
```
