# 🔐 Админ-Панель (только текстовые команды)

## 📋 Все команды

```
/admin          - Показать главное меню с командами
/stats          - Статистика БД
/masters        - Управление мастерами
/add_master     - Добавить нового мастера
/services       - Управление услугами
/clients        - Управление клиентами
/schedule       - Управление расписанием
/train          - Меню обучения ИНКИ
/add_example    - Добавить пример обучения
/view_examples  - Просмотреть примеры обучения
/improvements   - Предложения улучшений
/train_stats    - Статистика обучения
/cancel         - Отмена текущей операции
```

## 🚀 Быстрый старт

### 1️⃣ Включить админ-панель

```bash
# Добавить admin ID в .env
nano .env
ADMIN_IDS=123456789

# Перезапустить бота
python3 src/main.py
```

### 2️⃣ Использовать команды

```
/admin          - показать все команды
/stats          - увидеть статистику
```

## 🧠 Обучение ИНКИ - подробно

### Категории примеров

1. **greeting** - приветствия
   - "Привет!", "Добрый день", "Как дела?"

2. **booking** - запись на услугу
   - "Запиши меня", "На какой день?", "Есть ли свободное время?"

3. **question** - ответы на вопросы
   - "Сколько стоит?", "Какой опыт?", "Какие услуги?"

4. **help** - техническая помощь
   - "Как пользоваться ботом?", "Что-то не работает", "Помогите"

### Процесс добавления примера

```
/add_example
↓
Выбери категорию: greeting, booking, question, help
Введи: booking
↓
Что написал клиент?
Введи: "Я хочу сделать татуировку"
↓
Как должна ответить ИНКА?
Введи: "Конечно! На какую часть тела вы думаете?"
↓
✅ Пример добавлен!
```

## ⚠️ Решение проблем

### Ошибка: "У тебя нет прав администратора"

```
Решение:
1. Узнать свой Telegram user ID
2. Добавить в .env: ADMIN_IDS=твой_ID
3. Перезапустить бота
```

### Ошибка при добавлении мастера

```
Телефон должен начинаться с +
Правильно: +7-999-123-4567
Неправильно: 79991234567
```

### Примеры не появляются

```
Решение:
1. Подождать 5-10 секунд после добавления
2. Нажать /view_examples еще раз
3. Проверить интернет-соединение
```
