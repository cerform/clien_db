# 🚀 Админ-Панель: Быстрый старт (5 минут)

## ⚡ Включение админ-панели

### Шаг 1: Узнай свой Telegram User ID

```
1. Отправь боту любое сообщение
2. Отметь свой ID в логах бота (или спроси у разработчика)
3. ID выглядит так: 123456789
```

### Шаг 2: Добавь свой ID в конфиг

```bash
# Открой .env файл:
nano .env

# Добавь свой ID:
ADMIN_IDS=123456789

# Если несколько админов:
ADMIN_IDS=123456789,987654321,555666777

# Сохрани: Ctrl+X, затем Y, Enter
```

### Шаг 3: Перезапусти бота

```bash
# Останови текущий бот (Ctrl+C)
# Запусти заново:
python3 src/main.py
```

## 🔐 Безопасность

### Кто может использовать /admin?

✅ Только админы (указанные в ADMIN_IDS)
❌ Обычные клиенты не видят админ-меню

### Что админ может сделать?

✅ Добавить/просмотреть мастеров
✅ Добавить/просмотреть услуги  
✅ Посмотреть клиентов
✅ Обучить ИНКУ примерами
✅ Видеть статистику

❌ Не может удалять (только добавление/просмотр)
❌ Не может изменять цены (только просмотр)

## ⚠️ Частые ошибки

### Ошибка: "У тебя нет прав администратора"

```
❌ Неправильно:
- ADMIN_IDS не содержит твой ID
- Бот не перезапущен после изменения .env

✅ Исправить:
1. Узнай свой ID
2. Добавь в .env: ADMIN_IDS=твой_ID
3. Перезапусти бота
4. Попробуй /admin снова
```

### Ошибка при добавлении мастера

```
❌ "Телефон должен начинаться с +"
✅ Введи: +7-999-123-4567 (вместо 79991234567)

❌ Сообщение "что-то пошло не так"
✅ Проверь интернет и перепопробуй
```

## 💡 Советы и трюки

### Совет 1: Выбирай правильную категорию

```
Приветствие: "Привет", "Добрый день", "Как дела?"
Запись: "Запиши меня", "На какой день?", "Есть ли свободное время?"
Вопрос: "Сколько стоит?", "Какой опыт?", "Какие услуги?"
Помощь: "Как пользоваться ботом?", "Что-то не работает", "Помогите"
```

### Совет 2: Использование тегов

```
Теги помогают найти примеры потом:
- #booking - примеры о записях
- #tattoo - примеры о татуировках
- #price - примеры о ценах
- #urgent - срочные ситуации
- #complaint - жалобы/проблемы

Написание: booking,tattoo,small
(через запятую, без пробелов)
```

### Совет 3: Оценивай примеры

```
Когда добавляешь пример, оцени качество:
⭐ 1 звезда - плохой пример
⭐⭐ 2 звезды - может быть
⭐⭐⭐ 3 звезды - нормально
⭐⭐⭐⭐ 4 звезды - хороший
⭐⭐⭐⭐⭐ 5 звезд - отличный пример

ИНКА приоритезирует примеры с высокой оценкой!
```

### Совет 4: Исправляй ошибки ИНКИ сразу

```
Видишь неправильный ответ ИНКИ?
Не жди! Сразу:

1. /admin → 🧠 Обучить ИНКУ → ➕ Добавить пример
2. Добавь правильный ответ
3. ИНКА станет лучше уже через минуту

Чем быстрее исправляешь, тем выше качество!
```

## 📞 Техподдержка

### Проблема: Бот не отвечает на /admin

```
Решение:
1. Убедись что бот запущен (смотри на ПК, где запущен бот)
2. Убедись что ты админ (ID добавлен в ADMIN_IDS)
3. Перезапусти бота
```

### Проблема: Ошибка при добавлении примера

```
Обычно это ошибка интернета или БД

Решение:
1. Проверь интернет-соединение
2. Перепробуй еще раз
3. Если не работает - сообщи разработчику
```

### Проблема: Примеры не появляются

```
Решение:
1. Нажми "📚 Мои примеры" через 5-10 секунд после добавления
2. Если нет - нажми "🧠 Обучить ИНКУ" и вернись обратно
3. Если все еще нет - проверь интернет и повтори
```
