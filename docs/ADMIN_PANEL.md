# 🔐 Админ-Панель Telegram

Пользовательская система для управления БД и обучения ИНКИ прямо из Telegram.

## ⚡ Быстрый старт

```bash
# 1. Запустить бота
python3 src/main.py
# Выбрать: 2. ✅ Запустить бота

# 2. Отправить команду админа
/admin

# 3. Выбрать из меню:
#    📊 Статистика    - общая статистика БД
#    👥 Мастера       - управление мастерами
#    💼 Услуги        - управление услугами
#    👤 Клиенты       - управление клиентами
#    📅 Расписание    - управление расписанием
#    🧠 Обучить ИНКУ  - добавление примеров для обучения
#    📈 Статистика обучения - просмотр статистики ИНКИ
```

## 🏗️ Архитектура

### Компоненты

```
src/bot/handlers/
├── admin_panel.py          # Aiogram handlers для админ-меню
│   ├── AdminMenuHandler    # Класс обработчика
│   ├── AdminStates         # FSM states
│   └── router              # Aiogram router
│
src/services/
└── admin_db_manager.py     # БД операции + обучение ИНКИ
    ├── DatabaseManager     # CRUD операции
    ├── InkaLearningSystem  # Система обучения ИНКИ
    └── AdminAction enum    # Типы действий
```

### Поток данных

```
Пользователь (Telegram)
        ↓
   /admin command
        ↓
 AdminMenuHandler.show_admin_menu()
        ↓
   Inline Keyboard
        ↓
 CallbackQuery Handler
        ↓
   DatabaseManager / InkaLearningSystem
        ↓
   Google Sheets API
        ↓
 Обновленная БД
```

## 🔐 Безопасность

### Ограничение доступа

Только админы могут использовать команду `/admin`. Admin IDs настраиваются:

```bash
# В конфигурации
ADMIN_IDS=123456789,987654321
```

### Валидация данных

Все входные данные валидируются:

```python
# Телефон
✓ Должен начинаться с +
✓ Пример: +7-999-123-4567

# Email
✓ Проверка формата
✓ Пример: user@example.com

# Цена
✓ Положительное число
✓ Пример: 5000

# Рейтинг
✓ От 0 до 5
✓ Пример: 4.5

# Время
✓ Формат HH:MM
✓ Пример: 14:30
```

## 🔧 Интеграция с ИНКОЙ

### Добавление примеров улучшает ИНКУ

```
1. Админ добавляет пример:
   Категория: Запись
   Ввод: "Давайте запись"
   Ответ: "Конечно! Какой день вас устраивает?"

2. Пример сохраняется в INKA_Training sheet

3. ИНКА может использовать эти примеры для:
   - Few-shot learning
   - Улучшения ответов
   - Контекстуализации

4. Если админ исправляет неправильный ответ:
   Ввод: "Запиши меня"
   Было: "Что?"
   ✅ Должно быть: "Конечно! На какой день?"
   
   Это сохраняется как предложение улучшения
```

### INKA_Training Sheet

Структура автоматически создаваемого листа:

```
| Timestamp | User | Category | User Input | INKA Response | Correction | Tags | Rating |
|-----------|------|----------|------------|---------------|-----------|------|--------|
| 2024-01-15 | admin_123 | booking | "Запиши меня" | "Конечно!" | "Конечно! На какой день?" | booking,quick | ⭐⭐⭐⭐ |
```

## 🐛 Решение проблем

### Проблема: "У тебя нет прав администратора"

**Решение:**
```python
# Проверить что ADMIN_IDS содержит твой user_id

# Узнать свой user_id:
/admin
# Вывод: "У тебя нет прав администратора"
# Добавить свой ID в config/config.py:
ADMIN_IDS = [123456789]  # твой ID вместо 123456789
```

### Проблема: Не видны примеры обучения

**Решение:**
```bash
# Убедиться что лист INKA_Training создан:
1. Открыть Google Sheets документ
2. Проверить наличие листа "INKA_Training"
3. Если нет - добавить пример обучения (лист создастся автоматически)
```

### Проблема: Ошибка валидации телефона

**Решение:**
```
Телефон должен начинаться с + и содержать номер:
Правильно: +7-999-123-4567, +79991234567, +7 999 123 4567
Неправильно: 79991234567, 999-123-4567
```
