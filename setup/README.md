# 🔧 Setup - Инициализация БД

Скрипты для первоначальной настройки базы данных.

## 📋 Скрипты

### `init_database.py`
**Цель**: Создание схемы Google Sheets с необходимыми таблицами

**Таблицы**:
- `masters` - информация о мастерах
- `services` - услуги салона
- `schedule` - расписание мастеров
- `bookings` - записи клиентов
- `clients` - данные клиентов

**Использование**:
```bash
python setup/init_database.py
```

**Результат**: Пустая схема, готовая к заполнению данными

---

### `populate_database.py`
**Цель**: Общее заполнение базы данных

**Использование**:
```bash
python setup/populate_database.py
```

---

### `populate_real_data.py`
**Цель**: Заполнение тестовыми данными (3 мастера, 8 услуг, расписание)

**Мастера**:
- Анна Леви (tattoo) - реализм, черно-белая графика
- Платон Сосницкий (tattoo) - реализм, минимализм
- Мойше (piercing) - пирсинг, консультации

**Услуги**:
- Маленькая тату (30 мин, 3000₽)
- Средняя тату (60 мин, 5000₽)
- Крупная тату (120 мин, 8000₽)
- Текст (20 мин, 2000₽)
- Пирсинг (30 мин, 1500₽)
- И др.

**Расписание**: 7 дней × 3 мастера = 21 запись

**Использование**:
```bash
python setup/populate_real_data.py
```

**Результат**: Полностью готовая БД с тестовыми данными

---

## 🚀 Первоначальная настройка (одна команда)

```bash
# 1. Инициализировать схему
python setup/init_database.py

# 2. Заполнить тестовыми данными
python setup/populate_real_data.py

# 3. Проверить
python tests/pre_deploy_check.py
```

## 🔄 Повторное использование

Эти скрипты **идемпотентны** - можно запускать несколько раз без проблем.

Для очистки и переинициализации:
```bash
# Удалить все таблицы вручную в Google Sheets
# Или запустить init заново (пересоздаст схему)
python setup/init_database.py
```

## 🐛 Решение проблем

**Проблема**: "Таблица masters уже существует"
**Решение**: Удалить листы вручную в Google Sheets или пересоздать spreadsheet

**Проблема**: "Google Sheets API error"
**Решение**: Проверить:
1. GOOGLE_SPREADSHEET_ID в переменных окружения
2. GOOGLE_CREDENTIALS_JSON указан правильно
3. Service Account имеет доступ к таблице
