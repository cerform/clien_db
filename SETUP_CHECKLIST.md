## ⚙️ ФАЗА 5: ВАЖНЫЕ НАСТРОЙКИ (КРИТИЧНО!) (10-30 минут)

### 🔑 ОБЯЗАТЕЛЬНО: Добавить calendar_id для каждого мастера

**БЕЗ ЭТОГО ИНКА НЕ РАБОТАЕТ!**

```
Что это?
  calendar_id - уникальный ID для Google Calendar каждого мастера
  Пример: abc123def456@group.calendar.google.com

Как получить:
  1. Откройте Google Calendar (https://calendar.google.com)
  2. Создайте новый календарь для каждого мастера
     Нажмите "+" рядом с "Other calendars"
  3. Откройте Settings для календаря
  4. Нажмите "Integrate calendar"
  5. Скопируйте "Calendar ID"

Где вставить:
  1. Откройте Google Sheets (ваша БД)
  2. Откройте лист "Мастера"
  3. Найдите колонку "calendar_id"
  4. Вставьте calendar_id для каждого мастера

Проверка:
  python3 validate_db_inka.py
  # Должен показать что calendar_id заполнен
```

**Чеклист для добавления calendar_id:**

- [ ] Мастер 1: calendar_id добавлен?
- [ ] Мастер 2: calendar_id добавлен?
- [ ] Мастер 3: calendar_id добавлен?
- [ ] Проверка: `validate_db_inka.py` прошел успешно?

### ✅ РЕКОМЕНДУЕТСЯ: Проверить расписание

```
Что проверить:
  1. Лист "Расписание"
  2. Колонки:
     - master_id: содержит UUID мастера ✓
     - day_of_week: содержит monday/tuesday/etc ✓
     - start_time: содержит HH:MM формат ✓
     - end_time: содержит HH:MM формат ✓
     - is_working: содержит true/false ✓

Чеклист:
```

- [ ] Расписание заполнено для всех мастеров?
- [ ] day_of_week использует english названия (monday, не понедельник)?
- [ ] is_working = "true" для рабочих дней?
- [ ] is_working = "false" для выходных?
- [ ] start_time и end_time в формате HH:MM (не HH:MM:SS)?
